AI Self-Learning System

Автономная модульная платформа на Python с реестром задач и ML-пайплайнами

Архитектура Задачи Модули ML Репозиторий

О системе

Независимая система с расширяемой архитектурой плагинов на базе TaskRegistry. Предназначена для комплексной автоматизации: генерации отчетности со служебными штампами, обработки файлов и запуска алгоритмов машинного обучения.

Реестр задач (TaskRegistry)

generate_pdf

Создание PDF-документов с разметкой, структурой и защитным штампом.

organize_files

Автоматическая сортировка файлов по директориям (docs, code, data, models).

train / predict text

Обучение классификаторов и инференс текстовых данных (TF-IDF + Random Forest).

train / predict mol

Молекулярный анализ химических соединений по SMILES через RDKit.

Пайплайны и Инфраструктура

  • Ядро: Модульная структура в директории core/ с гибкой обработкой исключений и конфигураций.
  • Генерация отчетов: Использование ReportLab для сборки PDF с кастомными визуальными метками.
  • CI/CD: Автоматизированное тестирование через GitHub Actions (18+ проходящих тестов).
