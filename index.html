О проекте

AI Self-Learning System — это модульная платформа на Python, предназначенная для автоматизации задач машинного обучения, обработки данных и формирования отчетности. Система построена на базе гибкого реестра плагинов (TaskRegistry) и полностью протестирована с помощью автоматических CI/CD пайплайнов.

Возможности

  • Текстовый ML: Классификация текстов с помощью векторизатора TF-IDF и модели Random Forest.
  • Молекулярный анализ: Регрессионный анализ химических соединений (SMILES) с использованием дескрипторов RDKit.
  • Генерация отчетов: Автоматическое создание структурированных PDF-документов с помощью библиотеки ReportLab.
  • Архитектура плагинов: Удобная регистрация и выполнение новых задач через декораторы.
